## Questionário de briefing

Publicado em `gabrielfelix-ux.4yu.com.br/briefing/bertoncini-mendonca`.

Nove blocos, salvamento automático, e os dois sócios podem responder em
momentos diferentes sem apagar o que o outro escreveu. O código da página fica
no repositório do portfólio, não aqui.

## Restrições que valem para o design

A publicidade advocatícia é regulada pelo Provimento 205/2021 da OAB. Nada de
depoimento de cliente, caso de sucesso, número de processos, "consulta
gratuita", "especialista" sem título certificado, nem chamada com urgência. É
obrigatório exibir o número de inscrição de cada advogado e o registro da
sociedade. Detalhamento em `docs/PESQUISA.md`.
